# 日迹 · 备忘录工作台

按天记录「吃了什么 / 做了什么 / 心情状态 / 花费」，再用日历回看哪天做过同样的事。

---

## 一、先跑起来（不碰云端，30 秒）

> **在哪执行：本地电脑终端（Windows PowerShell）**
> 打开方式：按 `Win` 键 → 搜索 `PowerShell` → 回车。
> **不要**双击 `index.html`，浏览器直连 Supabase 会因 `file://` 报错，所以要用本地服务。

```powershell
# 第 1 步：切到项目目录（路径含中文，务必用引号包住）
cd "<项目目录>"

# 第 2 步：起本地服务（任选一条，装了哪个用哪个）
python -m http.server 8080 --bind 127.0.0.1
```

服务起来后**别关这个窗口**，浏览器打开：

```
http://127.0.0.1:8080
```

这时候是**纯本地模式**：功能全都能用，数据存在浏览器里，只是不会跨设备。

## 二、开云端同步（手机和电脑同一份）

一共三步，**每一步都会标明在哪执行**。

### 第 1 步：建表 —— 在网页控制台执行

1. 浏览器打开 [supabase.com](https://supabase.com)，用你自己账号登录
2. 进你**填 URL 的那个项目**（左侧 Project Settings 里能看到 Project URL，确认和 `config.js` 里的 `url` 一致）
3. 左侧菜单点 **SQL Editor** → **New query**
4. 打开项目里的 `supabase-memo-schema.sql`，**整段复制**粘进去
5. 点右下角 **Run**，看到 `Success. No rows returned` 就成了

> 这个脚本只新增 3 张 `memo_` 开头的表。
> **不会改、不会删你 couple-fatloss 用的 `sync_state` 表，也不动你库里任何现有数据。**

### 第 2 步：填 key —— 在本地编辑文件

1. 还在 Supabase 网页里，左侧 **Project Settings（齿轮）** → **API Keys**
2. 复制 **Project URL** 和 **anon public** 那串 key
3. 回到电脑，用记事本或 VS Code 打开 `js/config.js`，填进去：

```js
window.MEMO_SUPABASE = {
  url: "https://你的项目ID.supabase.co",
  anonKey: "eyJhbGciOi...(一长串)"
};
```

4. 保存 → 浏览器刷新 `http://127.0.0.1:8080`

刷新后右上角小圆点变**绿色**，就说明连上了。

### 第 3 步：让两个人的设备对上 —— 在网页里点

1. 打开工作台 → 左下 **设置**
2. **我是谁**：填你的名字（比如「小敏」）
3. **共享空间码**：两台设备要填**完全一样**的字符串

默认是 `memo-shared`。**想让记录更私密，就改成只有你们俩知道的一串**，比如 `suchen-2026-7f3a`，然后在他手机上也填同一串。

## 三、日常怎么用

| 想干的事 | 怎么做 |
|---|---|
| 打卡 | 日历页右侧「今天做到了」，点一下习惯就变成打勾 |
| 记一餐 | 右侧「吃了什么」下面点 `＋早餐` / `＋午餐`… |
| 记做的事 | 「做了什么」区 → `＋`，标签写「跑步、加班」这种，**日历上的点就是标签颜色** |
| 记心情 | 「心情与状态」区直接点 1~5 的数字，不用弹窗 |
| 记花费 | 「花费」区 → `＋`，填金额 |
| 看某天 | 日历上点那一天 |
| 看历史 | 左侧「流水」，可按类型筛、按标签筛、搜关键词 |
| 看坚持情况 | 左侧「统计」：每个习惯的本月次数、当前连续、最长连续、近 8 周色块 |
| 备份 | 设置页「导出 JSON 备份」，存哪儿都行 |

**日历上的圆点**：
- 习惯打卡 = 习惯自己的颜色
- 标签 = 按标签名固定分配的颜色（同一个标签永远同一个色，两台设备也一样）

## 五、想撤销怎么办

| 想撤销什么 | 怎么做 | 影响 |
|---|---|---|
| 关掉云同步 | 把 `js/config.js` 里的 url/key 清空，刷新 | 回到纯本地，云端数据还在 |
| 删掉云端那 3 张表 | Supabase SQL Editor 执行：`drop table if exists public.memo_logs, public.memo_entries, public.memo_habits;` | 只删这 3 张新表，减脂数据零影响 |
| 清空本机 | 设置页「清空本机数据」 | 只清这台设备，云端不动，重新拉取即可恢复 |

## 六、已知取舍（先说清楚）

1. **不用登录**。你和另一半共用一把 anon key，所以拿到这把 key 的人理论上能读到这 3 张表的内容——和你现有 `sync_state` 是同一个安全模型。别把 key 贴到公开仓库或群里。想更严实，告诉我，我改成邮箱登录 + 按用户隔离。
2. **冲突策略是「后改的赢」**。两台设备同时改同一条记录时，`updated_at` 更新的那条覆盖另一条。日常记录场景基本碰不到。
3. **删除是硬的**，删了就是删了（云端的也会同步删）。所以设置页留了导出备份。
4. 日历上现在最多显示 6 个点，超出的用 `+n` 表示。
